# 🪄 Яндекс Станция Мини 2 + Mac: Голосовой ассистент Qwen

Превратите вашу **Яндекс Станцию Мини 2** в персонального голосового помощника на базе больших языковых моделей (**Qwen 2.5 72B**, **Google Gemini**, **Claude**), глубоко интегрированного в экосистему **macOS**.

---

## ✨ Основные возможности

- 🧠 **Умнейший интеллект**: Вместо стандартных шаблонов Алисы с вами общается нейросеть уровня GPT-4 / Qwen 2.5 72B с памятью диалога и знанием контекста.
- 💻 **Полный контроль над Mac**:
  - Управление плеером **Apple Music** («Включи джаз», «Пауза», «Следующий трек»).
  - Поиск и открытие любых папок и файлов («Открой документы», «Открой папку school», «Покажи загрузки»).
  - Запуск любых приложений macOS («Запусти Safari», «Открой Telegram», «Запусти VS Code»).
  - Создание системных заметок и напоминаний («Напомни в 18:00 погулять с собакой»).
  - **Vision (зрение)**: Ассистент умеет мгновенно делать скриншот экрана Mac и отвечать на вопросы («Что у меня сейчас открыто на экране?», «Помоги решить задачу на экране»).
- 🔊 **AirPlay Аудио с ALSA dmix**:
  - Mac передаёт звук на колонку по AirPlay с мгновенным откликом.
  - Ассистент говорит поверх музыки или плавно приглушает её благодаря встроенному микшеру ALSA dmix (музыка и голос не блокируют друг друга).
  - Аппаратная шкала громкости защищена от перегрузки: музыка звучит чисто и комфортно.
- ⏰ **Анимированный LED-экран**:
  - Часы реального времени.
  - Температура погоды со знаком градуса `°` и минуса `-` (например, `+18°`, `-5°`).
  - Таймер обратного отсчёта.
  - Анимированный эквалайзер при воспроизведении музыки.
  - Смайлики и текстовая бегущая строка.
- 🎙️ **Аппаратная кнопка Mute**:
  - Нажатие на кнопку микрофона на колонке перехватывает ввод: звучит короткий звуковой сигнал, и колонка слушает вашу команду на Mac.

## 🚀 Быстрый старт (Установка в 1 клик)

Для установки вам понадобится Mac (с процессором Apple Silicon M1/M2/M3/M4 или Intel) и Яндекс Станция Мини 2 в одной локальной Wi-Fi сети.

### Вариант 1. Через Finder (самый простой)
1. Откройте папку `yandex-station-mac` в Finder.
2. Дважды кликните по файлу **`Setup.command`**.
3. В браузере откроется веб-мастер установки (`http://localhost:8899`).

### Вариант 2. Через Терминал
```bash
cd yandex-station-mac
./setup.sh
```

## 🌐 Что делает Веб-мастер установки?

1. **Автоматически находит Яндекс Станцию в домашней сети** через сетевое сканирование (порт SSH 2222 или 22).
2. **Проверяет валидность ваших API-токенов** (OpenRouter, Google Gemini или Groq Cloud) в один клик.
3. **Развёртывает всё под ключ**:
   - Сохраняет персональный `.env` файл.
   - Настраивает виртуальное окружение Python (через `uv` или стандартный `venv`).
   - Загружает скомпилированные ARM-бинарники (`mictap.so`, `touch-assistant`, `display-tool`, `shairport-sync`) на Станцию.
   - Прописывает автозапуск демона в `launchd` macOS, чтобы ассистент работал в фоновом режиме 24/7 даже после перезагрузки Mac.
   - Открывает веб-панель управления (Dashboard) на порту `8730`.

## ⚙️ Управление сервисом на Mac вручную

Если вам понадобится перезапустить или остановить ассистент:

```bash
# Перезапуск сервиса
launchctl kickstart -k gui/$(id -u)/me.station.assistant

# Остановка сервиса
launchctl bootout gui/$(id -u)/me.station.assistant

# Запуск сервиса
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/me.station.assistant.plist

# Просмотр логов в реальном времени
tail -f /tmp/station-assistant.log
```

Веб-панель мониторинга и тестирования доступна в браузере по адресу:
👉 **http://localhost:8730**

## ❓ Часто задаваемые вопросы и решение проблем

#### 1. Колонка не находится в сети автоматически
- Убедитесь, что колонка и Mac подключены к одному и тому же роутеру (одной подсети, например 192.168.1.x или 192.168.2.x).
- Введите IP адрес колонки вручную в мастере установки. Узнать IP можно в приложении вашего домашнего Wi-Fi роутера.

#### 2. Звук в Apple Music регулируется слишком громко/тихо
- В файлах `touch-assistant` и `system_tools.py` аппаратный уровень звука ограничен безопасным значением (до -8.0 dB), чтобы динамик Станции не хрипел. Шкала громкости настроена с учётом логарифмической кривой человеческого слуха.

#### 3. Как обновить бинарники на колонке?
- Просто запустите `./setup.sh` или выполните:
  ```bash
  ./scripts/deploy-station.sh 192.168.2.83 2222
  ```
